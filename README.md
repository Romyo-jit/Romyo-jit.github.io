# Personal Portfolio

A personal portfolio website built to showcase my projects, technical interests, skills, and progress as a developer.

**Live Website:** [romyo-jit.github.io](https://romyo-jit.github.io/)
**Source Code:** [github.com/Romyo-jit/Romyo-jit.github.io](https://github.com/Romyo-jit/Romyo-jit.github.io)

## About the Project

This website is my personal portfolio and a central place to present the projects I have worked on, the technologies I am learning, and some of my interests outside programming.

I built the site as a responsive single-page portfolio with separate sections for my introduction, background, skills, projects, current learning, and contact information.

The project has also served as an evolving record of my development as I learn new technologies and build more projects.

## Features

* Responsive personal portfolio layout
* Hero section with animated introductory text
* About section containing personal information and interests
* Skills section with visual skill indicators
* Project/resume section organized by project category
* Links to individual open-source projects
* Social-media and professional-profile links
* Contact section
* Responsive navigation for smaller screens
* Scroll-based animations
* Animated counters and UI elements
* Image and asset integration
* Mobile-friendly layout

## Technologies Used

### Core

* **HTML5** — page structure and semantic content
* **CSS3** — styling, layout, animations, and responsive design
* **JavaScript** — client-side interactivity and dynamic components

### Libraries and Frameworks

The website also uses several front-end libraries to provide reusable UI components and effects:

* **Bootstrap** — responsive layout and UI utilities
* **Bootstrap Icons** — interface icons
* **AOS (Animate On Scroll)** — scroll-based animations
* **GLightbox** — interactive image/lightbox functionality
* **Swiper** — interactive sliders and related UI components

The project loads typography from Google Fonts and keeps the main site styling in `assets/css/main.css`.

## Design

The website uses a section-based layout so that different aspects of my work can be accessed without navigating through multiple pages.

The main navigation provides access to:

* **Home** — introduction and visual identity
* **About** — background and interests
* **Resume** — skills and projects
* **Contact** — ways to reach me and links to my profiles

I chose a dark-background visual style and combined it with animations and responsive components to make the site feel interactive while keeping the information easy to navigate.

The portfolio also includes project descriptions and links to the corresponding source repositories. This allows the website to function not only as a personal profile but also as an index of my programming work.

## Development

The project was developed incrementally rather than as a single static page. I have continued modifying and improving the website as I learned more about web development and built new projects.

Git is used for version control, and the repository is publicly available so that the source code and development history can be inspected.

The website is deployed through **GitHub Pages**, with the repository serving as the source for the live site.

## Why I Built It

I wanted a place where I could document my progress and present my work in one location rather than keeping individual projects disconnected from each other.

Building the portfolio also gave me practical experience with:

* Structuring a complete web page with HTML
* Creating responsive layouts with CSS
* Adding client-side behavior with JavaScript
* Integrating third-party front-end libraries
* Organizing static assets
* Using Git and GitHub for version control
* Deploying a website publicly
* Iterating on a real project over time

The project therefore serves both as a portfolio and as a practical application of the web-development concepts I have learned.
